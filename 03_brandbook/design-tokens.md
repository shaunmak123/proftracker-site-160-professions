## 1. EVRAZ — «Молодёжная программа» (стиль стартовой страницы)

Источник: `EVRAZ/extracted/ББ ЕВРАЗ (молодежка)/Гайд_Molodezhnaya_programma_EVRAZa_2025_1.pdf`

### Шрифт
**Evraz Sans** — файлы уже в проекте (`EVRAZ/EvrazSans-*.otf`: Thin, Regular, Medium, Bold).

### Логотип
- Файл: `EVRAZ/Logo_Evraz.svg`, цветные/чб варианты — `EVRAZ/extracted/.../EVR_LOGO_RUS_*.ai`.
- Охранное поле = высота логотипа (минимальное — половина высоты, только когда места действительно мало).
- Три горизонтальные полоски слева — жёлтая/оранжевая/красная — часть логотипа, не трогать.
- На нашем сайте одного EVRAZ-логотипа (без ко-брендинга с вузом) достаточно — кобрендинг в гайде показан для примера сотрудничества с университетами, к нам не относится.

### Модульная сетка
Короткая сторона макета делится на 30 ячеек — основа для размещения бренд-арта (плашки, иллюстрации). Для веб можно упростить до 12-колоночной сетки, сохранив пропорции акцентных плашек.

### Персонажи и бренд-арт
- Есть иллюстрированные персонажи (девочки/мальчики-инженеры) и «маленькие помощники» (роботы, кот, дрон, птица) — использовать **только** те, что в гайде/хайрезах, не дорисовывать новые.
- Приём: тонкая рамка + «путеводная звезда» (акцентная точка/плашка) для лаконичных макетов без крупных иллюстраций — подходит для страницы профессии, где иллюстраций мало.
- Есть готовые примеры вёрстки сайта (стр. 25–26 гайда) — заголовок H1 крупный, акцентная плашка сбоку от иллюстрации, простая структура блоков.

### Тон коммуникации
Энергичный, «инженер-визионер», гордость за труд/производство. Игра слов вокруг слова «сталь» («времена сильных наСТАЛИ»). Подходит для коротких заголовков и кикеров на сайте.

## 3. Движение Первых — обязательная атрибуция (не основной стиль страницы)

Источники: `Dvizhenie_Pervykh/extracted/Брендбук/ПЕРВЫЕ_брендбук.pdf` (>20 МБ, не читался целиком) и `Dvizhenie_Pervykh/extracted/Фирменный стиль/.../` (логотипы, шрифты, элементы — цвета определены по пикселям файлов, т.к. текстовых HEX-значений в гайде нет).

### Цвета (по пикселям из логотипов/шаблонов)

| Источник | HEX | Комментарий |
|---|---|---|
| Логотип «Красный» | `#D90912` | Основной красный логотипа Движения Первых |
| Логотип «Синий» | `#3366CC` | Синий вариант логотипа |
| Декор «Грантового конкурса» (градиенты) | `#002C9D` → `#2A60EA` → `#A4B7F2` | Синий — доминирующий цвет **именно суббренда «Грантовый конкурс»** (соцсети, элементы оформления) |
| Чёрный / Белый | `#000000` / `#FFFFFF` | Монохромные варианты логотипа |

**Важно:** основной логотип ДП — красный (это символ движения), но материалы конкретно «Грантового конкурса» (в котором участвует наш проект) визуально построены на синем градиенте. Если делать блок атрибуции по их стилю — ориентироваться на синюю палитру грантового суббренда, а не на красный основной логотип.

### Шрифты (реальные названия из файлов, не только имена файлов)
- **Pervye Extended Bold** — заголовочный (`Шрифты/Заголовок.otf`)
- **Pervye Book** — основной текст (`Шрифты/Основной текст.otf`)

### Логотип
`Логотипы/Белый.png`, `Красный.png`, `Синий.png`, `Чёрный.png` — выбирать вариант по фону, на котором размещается.

### Обязательные требования (юридически значимо, не эстетика)
Из `04_документы_гранта/Положение_Осенняя_серия_ПрофиКвиз...pdf`, §9.3–9.4:
- На сайте должны быть хэштеги **#ДвижениеПервых #ГрантыПервых** и текст о том, что проект реализуется «при поддержке Общероссийского общественно-государственного движения детей и молодёжи «Движение Первых»».
- Материалы, купленные на грантовые деньги, должны нести символику/товарный знак Движения Первых.
- Практическая рекомендация: разместить это как блок в футере (текст + логотип, любой цветовой вариант, подходящий под фон) — не обязательно перекрашивать в это всю страницу.

## 4. Как это сочетать на сайте (когда дойдём до вёрстки)

- **Стартовая страница** — визуальный стиль EVRAZ «молодёжная программа»: цвета из блока 1, шрифт Evraz Sans, возможно один из «маленьких помощников» как акцент.
- **Футер / низ страницы (везде)** — обязательная атрибуция Движения Первых (текст + логотип + хэштеги) и, отдельно, копирайт/подпись АНО «ПРОФТРЕКЕР» как разработчика (можно с маскотом-котом).
- **Основной контент карточек профессий** — нейтральная тема из дизайн-хендоффа (`02_sources/.../design/industry-styles.css`) с подменёнными CSS-переменными на цвета EVRAZ, а не полное пересоздание вёрстки.

Вёрстку по этим токенам не начинаю — жду отдельного запроса, как договаривались.
